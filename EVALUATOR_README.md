# Volkswagen Assistant Demo — Android tester guide

## Install

1. Download **Volkswagen Assistant Demo.apk** on an Android 7+ phone or tablet.
2. Open the downloaded file.
3. If Android asks, allow installs from the browser or file manager you used.
4. Tap **Install**, then **Open**.

No account, API key, or setup screen is required in the evaluator build.

## Try it

1. Tap **Tap to talk**.
2. The first time only, allow microphone access.
3. Ask a question, then pause. You will see the transcript while speaking.
4. The answer appears and is read aloud. When Tako returns a card, it appears in glanceable mode on the right.

Example questions:

- “How did Volkswagen stock perform this month?”
- “What is the weather in Wolfsburg today?”
- “Compare Nvidia and AMD revenue over the last five years.”

## Troubleshooting

- If the app cannot hear you, open Android **Settings → Apps → Volkswagen Assistant Demo → Permissions** and allow the microphone.
- Turn up Android media volume if the written answer appears but is not spoken.
- The demo needs internet access.
- A message saying the build is no longer authorized means the temporary evaluation period has ended; ask the demo owner for a refreshed APK.

This is a prototype for evaluation, not a production vehicle HMI.
